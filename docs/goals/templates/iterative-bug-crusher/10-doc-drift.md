# Documentation Drift

## Audit Target

Find docs, comments, or project knowledge that are stale, misleading, missing, or inconsistent with current behavior.

## Inspect

- User guides, install/update docs, development docs, architecture notes, security docs, and comments near non-obvious behavior.
- Any behavior changed by fixes in this pass.

## Real Finding Criteria

The drift can cause a user, maintainer, release operator, or future agent to do the wrong thing.

## Fix Constraints

Update only documentation that materially helps future operation or maintenance.

## Verification Required

Confirm changed docs match actual commands, paths, behavior, and current constraints. Record what changed in the item notes.
