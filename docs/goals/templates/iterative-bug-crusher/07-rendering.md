# Rendering

## Audit Target

Find rendering bugs, layout collapse, overflow, clipping, visual contradictions, and broken responsive behavior.

## Inspect

- Route-level layouts, charts, tables, sidebars, right rails, drawers, cards, empty states, and dynamic labels.
- Desktop geometry first, then browser/demo/mobile surfaces.

## Real Finding Criteria

The issue makes information unreadable, hidden, overlapped, clipped, misleading, or unstable during normal use.

## Fix Constraints

Match the existing design system and verify at the relevant viewport or Electron geometry.

## Verification Required

Use screenshots, UI tests, or visual inspection for the changed surface. Record viewport and evidence in the item notes.
