# Browser and Demo Onboarding

## Audit Target

Improve browser/demo first-load clarity, speed, and confidence.

## Inspect

- Demo entry, local-first banners, generated data readiness, reset/import/export affordances, browser storage fallbacks, and landing-to-app flow.

## Real Opportunity Criteria

Users wait without feedback, misunderstand runtime limits, hit broken demo state, or see inconsistent onboarding between browser and desktop.

## Fix Constraints

Keep browser/demo runtime boundaries explicit and do not imply desktop-only guarantees.

## Verification Required

Use browser/demo route checks, screenshots, or first-load timing evidence. Record evidence in the item notes.
