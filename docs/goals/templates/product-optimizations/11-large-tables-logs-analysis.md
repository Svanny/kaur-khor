# Large Tables, Logs, and Analysis Views

## Audit Target

Improve performance and usability of dense tables, logs, inventory views, and analysis surfaces.

## Inspect

- Large row counts, sorting/filtering/search, table rendering, logs/activity history, inventory health views, analysis panes, and detail tables.

## Real Opportunity Criteria

The surface becomes slow, hard to scan, janky, memory-heavy, or visually unstable with realistic populated data.

## Fix Constraints

Preserve data correctness, accessibility, and table semantics. Avoid virtualizing or truncating data without clear UX behavior.

## Verification Required

Record fixture size, before/after timing or interaction evidence, and correctness checks in the item notes.
