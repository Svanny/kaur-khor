# Import, Export, and Persistence Flows

## Audit Target

Improve perceived speed and reliability of import, export, backup, restore, reload, and local persistence flows.

## Inspect

- File processing, progress feedback, blocking work, storage boundaries, reload behavior, snapshot/export size, and error/retry feedback.

## Real Opportunity Criteria

The flow feels frozen, blocks the UI unnecessarily, repeats expensive work, gives weak progress, or slows reload after organic updates.

## Fix Constraints

Do not weaken validation, checksums, backup safety, or user data separation for speed.

## Verification Required

Record before/after timing or UX evidence, data correctness checks, and any persistence boundary tested in the item notes.
