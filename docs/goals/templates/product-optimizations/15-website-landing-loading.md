# Website and Landing Page Loading

## Audit Target

Improve website and landing page loading behavior where it affects user perception.

## Inspect

- Above-the-fold media, responsive image sizes, lazy loading, asset compression, layout shift, loading priority, and landing-to-app/demo path.

## Real Opportunity Criteria

Images load too slowly, are oversized, cause layout shift, delay important content, or make the app/demo entry feel unreliable.

## Fix Constraints

Keep visuals inspectable and product-specific. Do not replace meaningful imagery with generic decorative assets.

## Verification Required

Record before/after asset size, load behavior, screenshots, Lighthouse-like output, or browser evidence in the item notes.
