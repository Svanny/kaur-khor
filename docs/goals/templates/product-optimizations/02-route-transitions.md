# Route Transitions

## Audit Target

Improve navigation responsiveness and route transition feel.

## Inspect

- Route loaders, provider reloads, detail hydration, deferred work, loading indicators, and back/forward behavior.

## Real Opportunity Criteria

Navigation feels frozen, repeats avoidable reads, blocks on noncritical work, or loses visible continuity.

## Fix Constraints

Keep data correctness and route-specific support reads explicit.

## Verification Required

Use navigation benchmarks, UI tests, or before/after interaction timing. Record evidence in the item notes.
