# Developer Feedback Speed

## Audit Target

Improve developer feedback speed only when it materially helps maintain product quality.

## Inspect

- Test targeting, benchmark scripts, build scripts, fixture setup, slow checks, and docs for running focused verification.

## Real Opportunity Criteria

Developers cannot run a focused check, checks do unnecessary work, or feedback speed discourages verifying real product behavior.

## Fix Constraints

Do not weaken release gates, skip meaningful coverage, or hide failures to make checks faster.

## Verification Required

Record before/after command behavior, timing if available, and coverage preserved in the item notes.
