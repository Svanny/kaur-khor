# Assets, Images, and Bundle

## Audit Target

Improve asset weight, image loading behavior, and bundle efficiency where user-visible.

## Inspect

- Landing visuals, screenshots, icons, lazy loading, responsive image sizing, dependency imports, and build output hints.

## Real Opportunity Criteria

Assets delay key content, are oversized for their use, load too early, cause layout shift, or bloat user-facing bundles.

## Fix Constraints

Keep important product visuals inspectable and avoid degrading brand or documentation assets.

## Verification Required

Use build output, asset sizes, Lighthouse-like checks, or before/after load evidence. Record evidence in the item notes.
