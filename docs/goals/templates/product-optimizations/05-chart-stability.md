# Chart Stability

## Audit Target

Improve chart loading, resizing, zooming, and visual stability.

## Inspect

- Chart panes, overlays, flags, resize observers, range changes, loading states, dense data, and expanded chart layouts.

## Real Opportunity Criteria

Charts flicker, collapse, misplace overlays, shift layout, lag during interaction, or misrepresent data density.

## Fix Constraints

Preserve calculation correctness and verify at full route geometry when layout is involved.

## Verification Required

Run chart-focused tests, screenshots, or interaction checks. Record viewport and evidence in the item notes.
