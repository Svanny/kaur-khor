# Demo Browser

## Audit Target

Test the public/demo browser experience and demo-data flows.

## Inspect

- Demo banners, generated data, reset controls, import/export affordances, navigation, landing-to-demo entry, and browser-only copy.

## Real Finding Criteria

Demo mode misleads users, fails to initialize/reset, breaks generated-state UI, or diverges from expected product behavior.

## Fix Constraints

Keep demo behavior clear and isolated from desktop userData assumptions.

## Verification Required

Verify the demo route with realistic viewport coverage. Record route, viewport, and evidence in the item notes.
