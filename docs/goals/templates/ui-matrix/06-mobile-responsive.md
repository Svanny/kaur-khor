# Mobile Responsive

## Audit Target

Test mobile and narrow responsive layouts.

## Inspect

- Navigation, sidebars/sheets, rotated phone views, tables, charts, long pages, forms, and touch-sized controls.

## Real Finding Criteria

Content overlaps, clips, becomes unreachable, switches to the wrong navigation mode, or breaks scrolling at mobile sizes.

## Fix Constraints

Verify at the actual target route and viewport; browser desktop views can miss embedded or mobile-specific bugs.

## Verification Required

Capture responsive screenshots or run mobile viewport tests. Record viewports in the item notes.
