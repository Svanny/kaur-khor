# Desktop Fresh State

## Audit Target

Test first-run and empty-workspace desktop behavior.

## Inspect

- App launch, default navigation, empty pages, empty tables/charts, disabled actions, onboarding copy, and safe defaults.

## Real Finding Criteria

The UI crashes, shows misleading metrics, leaks placeholders, enables impossible actions, or renders unstable empty states.

## Fix Constraints

Keep first-run behavior clear without inventing new onboarding flows unless required to fix a real defect.

## Verification Required

Verify the desktop app with a fresh workspace or deterministic fresh fixture. Record pages checked in the item notes.
