# Buttons, Forms, and Dropdowns

## Audit Target

Test core command controls and data-entry controls through actual interactions.

## Inspect

- Buttons, toggles, tabs, segmented controls, text inputs, numeric inputs, dropdowns, submit/cancel flows, disabled states, validation, and post-submit feedback.

## Real Finding Criteria

A control is unresponsive, performs the wrong action, accepts invalid input, loses input, lacks feedback, or leaves state inconsistent.

## Fix Constraints

Fix behavior and validation without changing unrelated layout or copy.

## Verification Required

Record the input state, interaction sequence, expected UI/data result, and command or screenshot evidence in the item notes.
