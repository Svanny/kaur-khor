# Main Navigation

## Audit Target

Test navigation between all major sections through real user paths.

## Inspect

- App launch, sidebar/top-level navigation, route changes, back/forward behavior, Settings return behavior, and cross-surface navigation parity.

## Real Finding Criteria

Navigation lands on the wrong page, drops state, breaks history, hides the current location, or fails on desktop/browser/demo/mobile.

## Fix Constraints

Preserve existing navigation semantics and verify affected history state, not just rendered route text.

## Verification Required

Record product target, routes visited, interactions used, expected result, and command or screenshot evidence in the item notes.
