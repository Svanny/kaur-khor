## Banji សម្រាប់អ្វី

Banji សម្រាប់ក្រុមដែលចង់បានកន្លែងធ្វើការស្តុកជាក់ស្តែងលើម៉ាស៊ីនតែមួយ ដោយមិនចាំបាច់ពឹងលើប្រព័ន្ធគ្រប់គ្រងខាងក្រោយនៅលើអ៊ីនធឺណិត។ វាសមស្របសម្រាប់៖

- រក្សាកាតាឡុក SKU និងសេវាកម្មដែលកំពុងប្រើ
- កត់ត្រាការផ្លាស់ប្តូរស្តុក និងសញ្ញាពាក់ព័ន្ធនឹងសេវាកម្ម នៅពេលវាកើតឡើង
- មើលថា អ្វីគួរធ្វើបន្ទាប់
- ពិនិត្យសញ្ញាផែនការ និងសញ្ញាអាជីវកម្មនៅលើម៉ាស៊ីនដដែល

Banji មិនមានគោលបំណងធ្វើជាដូចខាងក្រោមទេ៖

- ERP ពេញលេញ
- ប្រព័ន្ធ SaaS សម្រាប់អ្នកប្រើច្រើន
- ឧបករណ៍រៀបចំលំហូរការងារទូទៅ សម្រាប់គ្រប់គំរូស្តុក

ផលិតផលនេះមានទិសដៅច្បាស់។ បទពិសោធន៍ល្អបំផុតកើតឡើង នៅពេលអ្នកប្រើកាតាឡុក ការកត់ត្រាការអាប់ដេត និងការវិភាគរួមគ្នា។

## របៀបដែលលំហូរការងារសំខាន់ភ្ជាប់គ្នា

ក្រុមភាគច្រើននឹងប្រើ Banji តាមលំដាប់នេះ៖

1. សង់កាតាឡុកក្នុង **កាតាឡុក** ដោយបង្កើត SKU និងសេវាកម្ម។
2. កត់ត្រាស្ថានភាពពិតមួយក្នុង **កត់ត្រាការអាប់ដេត**។
3. ពិនិត្យការងារតាមដានភ្លាមៗក្នុង **ទិដ្ឋភាពទូទៅ**។
4. មើលប្រវត្តិដែលបានរក្សាទុកក្នុង **កំណត់ហេតុ**។
5. ពិនិត្យអាទិភាព និងសញ្ញាផែនការក្នុង **សុខភាពអាជីវកម្ម** និង **ការវិភាគ**។
6. កែប្រែចំណូលចិត្ត ការនាំចេញ ការបម្រុងទុក និងការគ្រប់គ្រងផែនការក្នុង **ការកំណត់**។

បើអ្នកទើបចាប់ផ្តើម៖

1. បង្កើត SKU ដំបូង។
2. បន្ថែមបណ្ដុំសេវាកម្មដែលពឹងលើ SKU ទាំងនោះ។
3. ដំណើរការការកត់ត្រាការអាប់ដេតលើកដំបូង។
4. ត្រឡប់ទៅទិដ្ឋភាពទូទៅវិញ ដើម្បីមើលថា Banji អាចបកស្រាយអ្វីពីទិន្នន័យដែលបានរក្សាទុក។

## ការរុករក និងការគ្រប់គ្រងសកល

បន្ទះរុករកខាងឆ្វេង គឺជាវិធីសំខាន់សម្រាប់ផ្លាស់ទីក្នុង Banji។ ទិសដៅកម្រិតលើមាន៖

- **ទិដ្ឋភាពទូទៅ**៖ ជំហានប្រតិបត្តិការបន្ទាប់ និងជួរបច្ចុប្បន្ន
- **កត់ត្រាការអាប់ដេត**៖ លំហូរការងារដែលមានការណែនាំ សម្រាប់កត់ត្រាអាប់ដេតថ្មី
- **សុខភាពអាជីវកម្ម**៖ តារាងអាទិភាព និងផ្ទៃសម្រាប់សម្រេចចិត្ត
- **កាតាឡុក**៖ កំណត់ត្រា SKU និងសេវាកម្ម
- **ការវិភាគ**៖ ផ្ទៃពន្យល់ជ្រាលជ្រៅសម្រាប់ SKU និងសេវាកម្ម
- **កំណត់ហេតុ**៖ ប្រវត្តិការអាប់ដេតដែលបានរក្សាទុក
- **បណ្ណសារ**៖ ធាតុកាតាឡុកដែលបានដាក់បណ្ណសារ
- **ការកំណត់**៖ ចំណូលចិត្តក្នុងម៉ាស៊ីន ការនាំចេញ សកម្មភាពបម្រុងទុក និងស្តារឡើងវិញ និងការកំណត់ផែនការ

អាកប្បកិរិយាសកលដែលគួរដឹង៖

- **បន្ទះរុករកដែលបង្រួម** លាក់អត្ថបទផ្នែក ប៉ុន្តែនៅតែអនុញ្ញាតឲ្យចូលទៅទំព័រទាំងអស់បាន។
- **ផ្ទាំងពាក្យបញ្ជា (`Cmd/Ctrl + K`)** ជាវិធីលឿនសម្រាប់ស្វែងរកទំព័រ ផ្ទាំង ធាតុ និងសកម្មភាព។
- **ស្ថានភាពកំពុងផ្ទុក** ជាទូទៅមានន័យថា Banji កំពុងបើកកន្លែងធ្វើការក្នុងម៉ាស៊ីន ធ្វើឲ្យទិន្នន័យថ្មី ឬគណនាវិភាគឡើងវិញ។
- **សារជំនួយ និងអត្ថបទជំនួយ** ពន្យល់ស្លាក និងសូចនាករជាច្រើន។ អ្នកអាចបន្ថយវាបានក្នុងការកំណត់ បើចង់បានផ្ទៃមុខស្ងប់ជាងមុន។

### ពេលណាគួរប្រើ

- ចាប់ផ្តើមវគ្គអាប់ដេតបន្ទាប់
- ពិនិត្យសកម្មភាពថ្មីៗ ដោយមិនចាំបាច់បើកប្រវត្តិពេញ
- បើក SKU ឬធាតុនៅជួរបន្ទាប់ដែលត្រូវពិនិត្យ

- ពិនិត្យអាទិភាពបញ្ជាទិញបន្ថែម

### ផ្ទាំងសំខាន់ៗ

#### ត្រូវធ្វើឥឡូវនេះ

- ត្រូវផ្លាស់ទីអ្វី
- ហេតុអ្វីបានជាឥឡូវនេះ
- ផលប៉ះពាល់ដែលរំពឹងទុក
- ប៊ូតុងសកម្មភាពមួយណា បើកទំព័រលម្អិតបន្ទាប់

#### ទិដ្ឋភាពប្រៀបធៀប

នេះជាទិដ្ឋភាពដែលជួយអ្នកប្រៀបធៀបតម្រូវការ ការគាំទ្រ ស្តុកកំពុងមកដល់ ស្ថានភាពចំណេញ និងសញ្ញាសំខាន់ៗរបស់ធាតុផ្សេងៗ ដោយមិនចាំបាច់ពិនិត្យមួយជួរម្ដង។

#### ប្រសិទ្ធភាពសាច់ប្រាក់ និងប្រាក់ចំណេញ

ផ្នែកនេះដាក់ធាតុជាក្រុមទៅក្នុងបណ្តុំដែលអនុវត្តបាន៖

- **ប្រាក់ចំណេញដែលត្រូវបានរារាំង**
- **សាច់ប្រាក់ជាប់គាំង**

ប្រើវា ដើម្បីយល់ថា ស្តុកដែលកំពុងដំណើរការ កំពុងជួយ ឬបង្កការកកស្ទះនៅកន្លែងណា។

#### ការទាញថយប្រតិបត្តិការ

#### ផ្លូវស្តារឡើងវិញ

ផ្នែកនេះបង្ហាញព្រឹត្តិការណ៍ ឬសញ្ញាដែលកំពុងមក ដែលអាចស្ដារសមត្ថភាព ឬធ្វើឲ្យភាពមានស្រាប់ប្រសើរឡើង។

#### តាមដានតម្លៃ និងប្រាក់ចំណេញ

ផ្នែកនេះដាក់ទង់សម្គាល់ធាតុដែលការពិនិត្យពាក់ព័ន្ធនឹងតម្លៃ ឬប្រាក់ចំណេញ គួរទទួលការយកចិត្តទុកដាក់។

#### ទំនុកចិត្ត និងការគ្របដណ្តប់

ផ្នែកនេះជួយអ្នកយល់ថា តើគួរជឿទុកចិត្តលើរូបភាពបច្ចុប្បន្នប៉ុនណា ជាទូទៅផ្អែកលើគុណភាពភស្តុតាង និងទិន្នន័យថ្មីៗ។
